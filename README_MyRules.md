# My Coding Rules

I will follow these coding rules consistently across my projects.

***Effective from `2026-10-20`***

**Note:** These rules are intended to be followed consistently from the effective date onward. Prior to the effective date, adherence to these rules may have been inconsistent. It may not have followed **all** these rules before the effective date.

## Python

### Python Naming Conventions

- **File Names**: `camelCase`
- **Directories**: `camelCase`
- **Variables**: `snake_case`
- **Functions**: `camelCase`
- **Classes**: `PascalCase`
- **Constants**: `SCREAMING_SNAKE_CASE`

## C Sharp
